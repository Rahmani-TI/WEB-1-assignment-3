 Task 0 — Responsive Typography
Created a simple webpage with a heading and paragraph.

 Tablet — medium font
 Mobile — small font


 Task 1 — Responsive Layout with Media Queries
Created three boxes using CSS Flexbox and Media Queries.
The layout changes according to the screen size:

 Desktop — three boxes in one row
 Tablet — two boxes in the first row and one box in the second row
 Mobile — boxes are stacked vertically

Bootstrap was not used for this task.
